# 탈옥 복구 도우미

리디페이퍼 4가 방전되어 탈옥이 해제됐을 때 탈옥을 복구할 수 있도록 안내하는 애플리케이션입니다.
> [!WARNING]
> 아직 테스트 중인 앱니다.

## 요구 환경

> [!IMPORTANT]
> 방전 후 탈옥 해제를 긴급하게 복구하는 앱입니다.  
> 이미 탈옥이 풀린 기기는 복구할 수 없습니다.

- 루팅(탈옥)된 리디페이퍼 4
- 펌웨어 1.0.9

## 설치

> [!WARNING]
> 이 앱을 설치하여 발생하는 고장 등의 모든 문제는 책임지지 않습니다.

1. 앱을 다운받아 설치합니다.
2. 앱을 열어서 루트 권한과 저장소 권한을 부여합니다.

## 사용 방법

1. 기기가 온전히 기동할 수 있도록 충분히 충전합니다.
2. 기기가 켜지고 10초 후 탈옥 해제 대화상자가 나타납니다.
3. `복구하기`를 누르면 자동으로 Magisk 모듈을 다시 활성화하고 재부팅합니다.
4. 다시 켜지고 10초 후 LSPosed로 이동하는 대화상자가 나타납니다.
5. LSPosed로 이동 후 `RP4Posed` 또는 `리페4 새로고침` 모듈을 활성화하고 재부팅합니다.
> [!CAUTION]
> 어떤 모듈을 켜든, `시스템UI`와 `시스템 프레임워크`가 체크되어 있음을 확인합니다.


## 망했어요!

대화상자를 실수로 닫았거나 자동 복구를 진행하지 못한 경우에는 ADB로 직접 복구할 수 있습니다.  

1. PC에서 기기 연결을 확인합니다.
```bash
adb devices
```

2. Magisk를 실행합니다.
```bash
adb shell monkey -p com.topjohnwu.magisk 1
```

3. 오른쪽 위 설정으로 들어가 `Zygisk`를 활성화합니다.
4. Magisk의 모듈 탭에서 비활성화된 모듈을 모두 켭니다.
5. 기기를 재부팅합니다.
6. 부팅이 완료되면 10초 후에 LSPosed Manager를 실행합니다.
```bash
adb shell am start -c org.lsposed.manager.LAUNCH_MANAGER com.android.shell/.BugreportWarningActivity
```

7. 모듈 탭에서 `리페4 새로고침`이나 `RP4Posed`를 활성화합니다.
8. 둘 중 하나만 활성화해야하며, `시스템UI`와 `시스템 프레임워크`가 체크되어 있음을 반드시 확인하십시오.
9. 재부팅
